# ROADMAP.md — Project Roadmap & Release Milestones

This document outlines completed milestones, upcoming feature enhancements, and future release targets.

---

## 🚩 Current Release (v1.0.0) — Complete

- [x] Next.js 16.2 App Router setup with Turbopack and React 19.
- [x] Tailwind CSS v4 design system with `@theme inline` tokens.
- [x] Centralized Framer Motion animation engine.
- [x] 11 complete portfolio sections (Hero, About, Experience, Skills, Projects, AI Engineering, Android, Research, Blog, Certifications, Contact).
- [x] Next.js Metadata API, dynamic `sitemap.xml`, `robots.txt`, dynamic favicon PNG generator, and JSON-LD schemas.
- [x] 100% static page prerendering across all routes.

---

## 🔮 v1.1.0 — Future Enhancements

- [ ] **MDX Blog Engine:** Local `.mdx` file parser integration for full-length technical blog posts.
- [ ] **Interactive AI Sandbox:** Client-side playground for testing synthetic multi-agent tool calling workflows directly in browser.
- [ ] **Light Mode Toggle:** Optional high-contrast light/dark theme switch adhering to strict monochrome palette tokens.
- [ ] **Multi-language i18n:** Built-in internationalization support for global technical recruiters.
